# Show Recent Prompts

Display the 10 most recent Claude Code prompts that were automatically saved.

## Usage
`/prompt-recent`

## Steps

1. Use the prompt manager to show recent prompts:
   ```bash
   /home/dariuszw/.Dotfiles/.claude/prompts/prompt-manager.sh recent
   ```

2. Display the results in a readable format showing date, time, and prompt title.

3. Suggest using `/prompt-show <id>` to view a specific prompt in detail.
