# Prompt Statistics

Show statistics about your saved Claude Code prompts.

## Usage
`/prompt-stats`

## Steps

1. Use the prompt manager to get statistics:
   ```bash
   /home/dariuszw/.Dotfiles/.claude/prompts/prompt-manager.sh stats
   ```

2. Display the statistics in a readable format.

3. Optionally show top tags or most active time periods if the data is available.
