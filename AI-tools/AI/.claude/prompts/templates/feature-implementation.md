# Feature Implementation Template

## Description
Use this template when requesting help implementing a new feature.

## Template
```
I need help implementing ${FEATURE_NAME} for ${PROJECT_NAME}.

**Feature Description:**
${FEATURE_DESCRIPTION}

**Requirements:**
- ${REQUIREMENT_1}
- ${REQUIREMENT_2}
- ${REQUIREMENT_3}

**Technical Constraints:**
- ${CONSTRAINT_1}
- ${CONSTRAINT_2}

**Current Architecture:**
${ARCHITECTURE_DESCRIPTION}

**Proposed Approach:**
${PROPOSED_APPROACH}

**Acceptance Criteria:**
- [ ] ${CRITERIA_1}
- [ ] ${CRITERIA_2}
- [ ] ${CRITERIA_3}

**Files to Modify/Create:**
${FILES_LIST}

**Dependencies:**
${DEPENDENCIES}

Please help me:
1. ${HELP_ITEM_1}
2. ${HELP_ITEM_2}
3. ${HELP_ITEM_3}
```

## Variables
- ${FEATURE_NAME} - Name of the feature to implement
- ${PROJECT_NAME} - Name of the project
- ${FEATURE_DESCRIPTION} - Detailed description of what the feature should do
- ${REQUIREMENT_1}, ${REQUIREMENT_2}, ${REQUIREMENT_3} - Specific requirements
- ${CONSTRAINT_1}, ${CONSTRAINT_2} - Technical or business constraints
- ${ARCHITECTURE_DESCRIPTION} - Overview of current system architecture
- ${PROPOSED_APPROACH} - Your initial approach or ideas
- ${CRITERIA_1}, ${CRITERIA_2}, ${CRITERIA_3} - Success criteria
- ${FILES_LIST} - Files that need to be created or modified
- ${DEPENDENCIES} - External dependencies or prerequisites
- ${HELP_ITEM_1}, ${HELP_ITEM_2}, ${HELP_ITEM_3} - Specific help needed

## Usage
```bash
prompt-manager template feature-implementation
```
